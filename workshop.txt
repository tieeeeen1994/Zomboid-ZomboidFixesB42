title=Zomboid Fixes B42.20
description=A set of fixes for Build 42.20, mostly for multiplayer. Install it on both the server and clients. Fixes marked optional are off by default and can be turned on in sandbox options.
description=
description=[list]
description=[*]Fast Timed Actions makes item transfers quick in multiplayer, like in single player.
description=[*]Changing an animal's gender in the animal info window also changes its model and type, and no longer reverts for other players.
description=[*]The foraging debug menu can add, move and refresh icons, and added icons can be picked up.
description=[*]Item editor changes save for items in crates, vehicles, on the floor and in other players' inventories.
description=[*]Debug Add Fluid fills rain collectors and other world containers instead of emptying them.
description=[*]The admin tag shows for every admin panel cheat. It can also be hidden completely (optional).
description=[*]Metal Shin Armor and Articulated Metal Shin Armor no longer have their run speeds swapped.
description=[*]No fall damage on stairs while Fast Move is on (optional, beta).
description=[*]Items with negative weight are deleted (optional).
description=[*]Clothing destroyed while worn stays destroyed after relogging (optional).
description=[*]Chickens the game deletes after laying in a full hutch are put back (optional).
description=[*]Hutches and nest boxes can be set to get dirty more slowly (optional).
description=[*]Running into a stair railing no longer vaults you over it (optional).
description=[*]Speed controls are back in multiplayer. The game fast forwards once every player votes for it (optional, beta).
description=[*]Guns of Marz attachment tooltips wrap instead of stretching across the screen (optional).
description=[/list]
